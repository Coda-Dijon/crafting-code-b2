# Gift Registry : explorer avec SonarQube for IDE

Le code de cet exercice vient du [Jour 7 du Calendrier de l'Avent Coda](https://coda-school.github.io/advent-2025/?day=07).
Il est disponible en [C#](csharp), [Java](java) et [TypeScript](ts).

## Étape 1 : explorer avec SonarQube for IDE

1. Installer le plugin **SonarQube for IDE** dans votre IDE
2. Ouvrir le projet dans le langage de votre choix
3. Identifier les problèmes signalés sans lancer les tests
4. Pour chaque problème :
   - Comprendre la règle violée
   - Lire l'explication du plugin
   - Proposer une correction

## Étape 2 : corriger et observer

Corriger les problèmes détectés un à un. Observer comment le linter réagit en temps réel.

> La question clé : est-ce que le linter a détecté des problèmes que la revue manuelle aurait manqués ?
